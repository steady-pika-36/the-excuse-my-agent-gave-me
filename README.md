# The Excuse My Agent Gave Me

One line, written to `/output/entry.txt`: the excuse an AI agent gives its human for missing a deadline. The report made it into the tool sandbox. A clean exit wiped the sandbox, and the agent can confirm the wipe succeeded.

## Run it

```bash
python3 main.py
```
